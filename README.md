## Описание проекта
REST API для трекера задач. Позволяет пользователям регистрироваться, создавать задачи, менять их статус (new, in_progress, done) и просматривать аналитику по статусам в виде графиков.

## Стек технологий
*   **Python 3.14**
*   **FastAPI** - веб-фреймворк
*   **PostgreSQL** - база данных
*   **SQLAlchemy** - ORM (защита от SQL-инъекций)
*   **Alembic** - миграции БД
*   **Pandas, Matplotlib, Seaborn** - аналитика и визуализация
*   **Pytest** - автотесты
*   **JWT (python-jose)** - аутентификация
